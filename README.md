# Homebrew tap for swarmy

```sh
brew install koorchik/tap/swarmy
```

[swarmy](https://github.com/koorchik/swarmy) watches your Claude Code, Antigravity and Codex
agents live, with their spend at API prices and your weekly limits, in one terminal.

`Formula/swarmy.rb` is written by swarmy's release workflow; do not edit it by hand.
